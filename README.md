# Anime Survivors

Небольшая аркадная игра в жанре survivor/auto-battler с аниме-стилем, вдохновлённая классическими играми вроде Vampire Survivors. Игрок выбирает одну из четырёх героинь, выживает в волнах врагов, собирает опыт, открывает сундуки и улучшает персонажа в процессе боя.

## О проекте

В проекте реализован полноценный игровой цикл:

- выбор героя перед стартом;
- управление персонажем клавиатурой или курсором/тач;
- автоматические атаки по врагам;
- волновая система с нарастающей сложностью;
- боссовые волны;
- система уровней и улучшений;
- сохранение рекорда в localStorage;
- пауза, экран смерти и меню игры.

Игра собрана на React + Vite + TypeScript и работает в браузере через canvas-рендер.

## Главные особенности

### 4 героини с разным стилем игры

Каждый персонаж имеет уникальные параметры:

- Сакура — высокая скорость атаки;
- Юки — более точные/замораживающие снаряды;
- Хина — мощный урон, но более медленная атака;
- Мико — несколько снарядов при меньшем уроне.

### Выживание и волны

Игра идёт по 30 волнам. Каждая волна включает врагов разного типа и уровня сложности. Со временем появляются:

- обычные враги;
- быстрые/мелкие противники;
- более тяжёлые враги;
- боссовые сущности.

### Система улучшений

После достижения нового уровня игрок получает выбор из нескольких улучшений. Можно усиливать:

- урон;
- скорость движения;
- скорость атаки;
- здоровье и броню;
- количество снарядов;
- скорость и размер снарядов;
- радиус притягивания опыта;
- восстановление здоровья.

### Сундуки и награды

Во время волн появляются сундуки с разными типами наград:

- лечение;
- усиление урона;
- ускорение;
- случайное улучшение.

### Рекорд и игровой прогресс

- сохраняется лучший результат по времени выживания;
- в игре есть экран паузы и проигрыша;
- состояние сессии обновляется в реальном времени.

## Технологии

- React 18
- TypeScript
- Vite
- Canvas API
- CSS / Tailwind-style utilities
- Node.js test runner для unit-тестов

## Как запустить проект

1. Установите зависимости:

   npm install

2. Запустите локальный dev-сервер:

   npm run dev

3. Откройте приложение в браузере по адресу, который покажет Vite.

## Дополнительные команды

- Проверка типов:

  npm run typecheck

- Запуск тестов:

  npm test

- Сборка проекта:

  npm run build

## Структура проекта

- src/App.tsx — основная логика UI и игровой цикл
- src/game/ — ядро геймплея: движок, волны, враги, апгрейды, рендер
- src/ui/ — экраны меню, выбора персонажа, паузы, победы/проигрыша
- src/gameLogic.ts — вспомогательная логика генерации волн и опыта
- src/gameLogic.test.ts — тесты игровой логики

## Управление

- W, A, S, D или стрелки — движение
- ESC — пауза
- Клик по улучшениям — выбор апгрейда
- Горячие клавиши для выбора улучшений также поддерживаются в игровом цикле

## Цель игры

Нужно выжить как можно дольше, уничтожая врагов, собирая опыт и постепенно усиливая персонажа до тех пор, пока волны не станут неосуществимыми.

## Примечание

Проект является учебным/демонстрационным game prototype и хорошо подходит как база для дальнейшего развития: новых персонажей, предметов, эффектов, музыки, уровней и более сложных механик.
