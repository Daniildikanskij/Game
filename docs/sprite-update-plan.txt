Дата: 2026-09-19

Цель
----
Заменить эмодзи в персонажах, врагах и сундуках на полноценные спрайты и текстуры, сохранив Canvas-рендеринг, анимации стихий и fallback на случай загрузки ассетов.

Форматы
--------
- PNG или WebP с прозрачностью для персонажей, врагов и объектов.
- Sprite sheet для анимированных сущностей.
- Canvas-геометрия оставить для свечения, частиц, следов, полос здоровья и прочих процедурных эффектов.
- Для крупных объектов использовать отдельные изображения, чтобы упростить замену ассетов.

Sprite sheet
------------
Пример сетки персонажа 64x64:

idle_1 | idle_2 | idle_3 | idle_4
walk_1 | walk_2 | walk_3 | walk_4
hit    | cast   | defeat | -

Описание спрайта должно содержать:
- src;
- frameWidth;
- frameHeight;
- columns;
- rows;
- при необходимости frame ranges для idle, walk, hit, cast и defeat.

Архитектура
-----------
1. Создать src/game/assetLoader.ts.
2. Добавить кэш HTMLImageElement по пути ассета.
3. Реализовать безопасную загрузку изображений.
4. Пока изображение не готово, использовать fallback: цветной силуэт, круг или текущую геометрию.
5. Добавить SpriteDefinition в типы.
6. Добавить sprite-поля в конфигурации персонажей, врагов и сундуков.
7. Добавить состояние анимации: frame и timer.
8. Вынести drawSprite(ctx, image, definition, frame, x, y, width, height) в renderer.

Порядок миграции
----------------
1. Добавить загрузчик и кэш изображений.
2. Заменить спрайтами персонажей.
3. Заменить одного обычного врага и проверить масштабирование.
4. Заменить остальные типы врагов и босса.
5. Заменить четыре типа сундуков.
6. Добавить idle и walk-анимации.
7. Добавить hit и defeat-состояния.
8. Заменить визуал снарядов и добавить hit-effects.
9. Добавить тайлы земли, стену и визуальную границу карты.
10. После проверки убрать emoji-поля или оставить их только как fallback-описание.

Стихийные эффекты
-----------------
Огонь:
- спрайт искры или огненного ядра;
- оранжевый trail;
- частицы углей при попадании.

Лёд:
- кристаллический снаряд;
- холодное кольцо;
- короткие осколки при попадании.

Молния:
- ядро снаряда;
- отдельный разряд между основной целью и цепной целью;
- короткий вспышечный эффект.

Тень:
- тёмный снаряд;
- дымный фиолетовый след;
- кольцо метки вокруг отмеченного врага;
- отдельный спрайт теневого взрыва.

HUD и интерфейс
---------------
- Добавить иконки стихий и апгрейдов в HUD.
- Использовать изображения только для игровых иконок, а кнопки оставить на lucide-react или текстовых командах.
- Сохранить fallback-иконки до полной миграции ассетов.
- Проверить, что изображения не разъезжаются на мобильных экранах.

Технические требования
----------------------
- Не блокировать игровой цикл во время загрузки изображений.
- Не создавать новый Image каждый кадр.
- Использовать единый кэш ассетов.
- Учитывать devicePixelRatio и логические размеры Canvas.
- Не менять физические размеры сущностей при переключении между fallback и спрайтом.
- Обрезать спрайт по frameWidth и frameHeight.
- Не масштабировать изображения через CSS, если они рисуются внутри Canvas.

Проверки
--------
После каждого этапа запускать:
- focused unit tests для renderer и canvas;
- полный node test suite;
- TypeScript typecheck;
- production build.

Визуально проверить:
- персонажей и врагов на desktop и mobile;
- загрузку первого кадра без ассетов в кэше;
- корректность прозрачности;
- отсутствие мерцания при смене кадров;
- положение спрайтов у границ карты;
- масштабирование на DPR 1 и DPR 2;
- читаемость HUD и карточек улучшений.

Критерии готовности
-------------------
- Ни один основной игровой объект не зависит от emoji как от единственного визуала.
- Все ассеты загружаются через общий кэш.
- При ошибке загрузки игра продолжает работать с fallback.
- Анимации не меняют размеры hitbox и игровую логику.
- Все тесты и production build проходят.
- README обновлён после фактической реализации, а не только после создания плана.
