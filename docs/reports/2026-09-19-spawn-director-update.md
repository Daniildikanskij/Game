# Отчет: переработка механики спавна противников

## Дата
2026-09-19

## Причина изменения

Раньше враги появлялись через случайную проверку на каждом кадре. Из-за этого одна и та же волна могла долго оставаться пустой, а затем выпускать врагов слишком плотной серией. При этом скорость спавна зависела от частоты кадров и не давала стабильного темпа волны.

## Что изменено

1. Добавлен управляемый интервал спавна для каждой волны.
2. Интервал вычисляется один раз при запуске волны на основе общего количества врагов и длительности волны.
3. В `WaveRuntime` добавлен накопитель времени спавна.
4. За один кадр разрешено выпускать ограниченный burst из двух врагов.
5. В последние секунды волны допускается burst до трёх врагов, чтобы очередь гарантированно не зависала.
6. Если время волны закончилось, оставшиеся враги выпускаются ограниченными порциями, а переход выполняется после их уничтожения.
7. Добавлена функция `getWaveSpawnInterval()` с минимальным интервалом `0.18` секунды для защиты от слишком резкого скопления врагов.

## Игровой результат

- темп волны стал предсказуемым;
- враги распределяются по большей части длительности волны;
- поздняя часть волны может становиться плотнее без мгновенного выброса всей очереди;
- при большом количестве врагов не возникает спавна сотен целей за один кадр;
- детерминированный seed сохраняет воспроизводимость состава и порядка очереди.
