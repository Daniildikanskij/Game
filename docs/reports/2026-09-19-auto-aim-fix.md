# Отчет: исправление автоприцела

## Дата
2026-09-19

## Проблема

При нескольких снарядах автоприцел добавлял фиксированный разброс к направлению каждого выстрела. Если рядом находился один враг, часть снарядов проходила мимо цели. В выбор цели также могли попадать враги с `hp <= 0`, пока они ещё не были удалены из массива.

## Исправление

- выбор целей вынесен в `getAimedTargets()`;
- мёртвые враги исключаются из прицеливания;
- живые цели сортируются по дистанции до игрока;
- разные снаряды получают ближайшие доступные цели;
- если цель одна, все снаряды направляются точно в неё;
- искусственный разброс удалён из автоприцела.

- focused engine tests: **10 passed, 0 failed**;
- полный test suite: **34 passed, 0 failed**;
- production build: успешно.
